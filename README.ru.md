# Pocket Code Studio

**Файлы сервера и привычный редактор кода — в одном PHP-файле.**

Файловый менеджер и веб-редактор для собственного сервера с интерфейсом, вдохновлённым Visual Studio Code. Проект развивается [Renat2985](https://github.com/Renat2985) на основе работ Joseph Chuks и использует Ace.

## Возможности

- Внутренние вкладки, индикатор несохранённых правок, восстановление вкладок, курсора и прокрутки после перезагрузки. Текст несохранённых документов в cookie не хранится.
- Дерево папок слева, изменение ширины панели с сохранением в cookie, поиск и сортировка файлов.
- Меню File / Edit / View / Tools / Help, компактная строка состояния, выбор языка и размера шрифта.
- Подсветка синтаксиса, поиск и замена, undo/redo, перенос строк, явное форматирование поддерживаемых языков.
- Минимап с навигацией и отметки повторений выделенного текста.
- Темы всего интерфейса: Theme Mix, One Dark, Nord, Dracula, Monokai и другие. Меню, окна и полосы прокрутки следуют выбранной теме.
- Встроенные иконки файлов и специальных папок Material Icon Theme; резервные иконки Seti.
- Создание, переименование, копирование, перенос, загрузка и скачивание; корзина, восстановление, права доступа и архивы при поддержке сервером.
- Git: статусы файлов и сравнение с последним коммитом, включая несохранённые правки. Коммитов, переключения веток и отката нет.
- Авторизация по паролю, CSRF, ограничение попыток входа, истечение сессии и смена пароля в настройках.
- Проверка версии файла перед сохранением, резервная копия и проверенная запись через временный файл.

## Запуск

На сервер нужен только **`filemanager.php`**. База данных, Composer и сборка Node.js не нужны. Библиотеки JavaScript/CSS загружаются с CDN, поэтому браузеру нужен интернет.

1. Нужны PHP 7.4+ (предпочтительно актуальная поддерживаемая версия), сессии, доступ к файловой системе и HTTPS. Для локального адреса `127.0.0.1` HTTPS не требуется.
2. Пароль по умолчанию — **`admin123`**. Имя пользователя не требуется. Сразу после входа смените пароль через **File → Settings → Change password**, до открытия публичного доступа к менеджеру.
3. При желании задайте свой пароль до загрузки: создайте хеш командой ниже и вставьте результат в `$authPasswordHash` в начале PHP-файла. Открытый пароль в эту строку записывать нельзя.

   ```sh
   php -r 'echo password_hash(readline("New password (input is visible): "), PASSWORD_DEFAULT), PHP_EOL;'
   ```

4. Проверьте `$config['root_path']`: по умолчанию это корневая папка сайта. Ограничьте доступ нужной вам директорией.
5. Загрузите настроенный файл и откройте его по HTTPS. На Apache/Nginx PHP должен получать корректный серверный параметр `HTTPS=on`.

Пароль меняется в **File → Settings → Change password**. Для этого PHP должен иметь возможность заменить собственный файл. Настроенную копию со своим хешем не публикуйте в репозитории.

## Сохранение и ограничения

Защита относится ко всем действиям **через файловый менеджер**. Обычный сайт остаётся публичным; доступ по прямым URL регулирует веб-сервер.

Редактор сохраняет UTF-8 BOM и единые переводы строк LF/CRLF/CR. Бинарные файлы, другие кодировки, смешанные переводы строк, жёсткие ссылки и файлы больше 8 МБ не редактируются. Изменение файла на диске после открытия вызывает конфликт сохранения. Само сохранение не форматирует код и не проверяет его синтаксис.

Резервные копии находятся вне сайта в приватной временной папке PHP. Хостинг может очистить её: это дополнение к постоянным бэкапам, а не замена. Внешние программы могут не учитывать блокировку редактора; ACL и расширенные атрибуты файлов не гарантируются. Подробности — в [английском README](README.md#security-and-file-saving).

Для Git нужны установленный Git и разрешённый `proc_open`. Корень рабочей папки должен совпадать с корнем репозитория. Сравнение открывается через **Tools → Git: View changes against HEAD**. Без Git остальные функции продолжают работать.
