# Credits

**Pocket Code Studio** is maintained by [Renat2985](https://github.com/Renat2985).

This project develops the original [PHP File Manager with Code Editor](https://github.com/JosephChuks/php-file-manager-with-code-editor) by **Joseph Chuks** and integrates his [CWP Code Editor](https://github.com/JosephChuks/cwp-codeEditor). They are the codebase origins, not a PHP framework.

Pocket Code Studio adds the single-file workspace, internal tabs and restoration, explorer behavior, unified themes, minimap, occurrence overview, embedded file icons, protected authentication, verified saves, and read-only Git comparison described in the README. Original authorship is retained.

- [Ace](https://github.com/ajaxorg/ace): editing engine.
- [Prettier](https://github.com/prettier/prettier) and [PHP plugin](https://github.com/prettier/plugin-php): explicit code formatting.
- [Bootstrap](https://github.com/twbs/bootstrap): interface components.
- [Font Awesome](https://github.com/FortAwesome/Font-Awesome): interface icons.
- [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme): file and folder SVGs loaded from jsDelivr.
- [Seti UI](https://github.com/jesseweed/seti-ui) / [VS Code Seti theme](https://github.com/microsoft/vscode/tree/main/extensions/theme-seti): fallback file-icon font and associations.
- [CoolAlert](https://www.npmjs.com/package/coolalertjs): alerts (the deployed CDN package is `coolalertjs`).
- [HTMX](https://github.com/bigskysoftware/htmx): existing client dependency.

The interface is inspired by Visual Studio Code. Pocket Code Studio is an independent project and is not affiliated with, endorsed by, or built on Microsoft Visual Studio Code. Its application favicon is an original simple code-brackets design.

## Color themes

Ace themes load from the pinned ace-builds CDN. The interface palette is derived from the selected theme.
