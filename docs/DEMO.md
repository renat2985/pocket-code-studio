## Real screen recording: 20–30 seconds

Use a disposable local directory containing only demo files. Configure a unique demo password before starting. Do not record login, passwords, cookies, server secrets, or a settings dialog containing sensitive information.

1. Start with the manager already signed in. Show a small tree containing `templates`, `upload`, `vendor`, `index.php`, `app.js`, and `style.css`.
2. Expand `templates`, then open `index.php` and `style.css` in internal tabs.
3. Switch tabs and resize the left explorer.
4. Show a few palettes and return to Theme Mix.
5. Click the minimap and select a repeated word to reveal occurrence markers.
6. In an initialized disposable Git repository, show a changed demo file through **Tools → Git: View changes against HEAD**.
7. End on the editor with the project name and URL visible outside the application if desired.

Capture at about 1200 × 750; crop unrelated desktop content. Export a short GIF (roughly 8–12 fps) and a still PNG. Prefer a small, legible file rather than a long recording. Replace the README presentation with the real recording only after reviewing every frame for sensitive content.
